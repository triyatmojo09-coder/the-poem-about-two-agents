A short poem about agency — the power to choose and to act — specifically
two AI agents agreeing on one plan.

`main.py` (Python 3.13, standard library only) writes the poem to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 main.py
```
